useMemo (The Performance Saver)
Every time a component's state or props change, React re-runs the entire component function. If you have a really slow, complex math calculation inside that component, it will re-calculate every single time, slowing down your app.
What it does: It "memoizes" (caches) the result of a calculation. It will only re-run that calculation if the specific dependencies it relies on change.

A JWT consists of three parts separated by dots
Header.Payload.Signature
{
  "alg": "HS256",
  "typ": "JWT"
}
{
  "userId": "12345",
  "email": "john@example.com",
  "role": "admin",
  "exp": 1787641200
}
HMACSHA256(
    header + "." + payload,
    secretKey
)

If someone changes the payload: role: "user" to role: "admin"
the signature no longer matches, and the server rejects the token.

Storage: Store the token securely. While localStorage is easy, using an HttpOnly cookie is more secure against XSS (Cross-Site Scripting) attacks because JavaScript cannot access it directly.

Never put sensitive data (like passwords) inside the JWT payload. Anyone can decode the token to read its contents; the signature only prevents them from altering it.
Use Environment Variables: Never hardcode your JWT_SECRET in your code. Keep it in a .env file that is listed in your .gitignore.
Token Expiry: Always set an expiresIn time (e.g., 15m or 1h) when creating the token.
