useState: It allows a component to remember values between renders and triggers

useContext: Normally in React, if a parent component has data that a deeply nested child component needs, you have to pass it down manually through every single component in between (a frustrating process known as "prop drilling"). useContext solves this.

useMemo (The Performance Saver)
Every time a component's state or props change, React re-runs the entire component function. If you have a really slow, complex math calculation inside that component, it will re-calculate every single time, slowing down your app.
What it does: It "memoizes" (caches) the result of a calculation. It will only re-run that calculation if the specific dependencies it relies on change.
